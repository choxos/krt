# The validation report object

[`validate_krt()`](https://choxos.github.io/krt/reference/validate_krt.md)
returns a `krt_validation_report`. It has
[`print()`](https://rdrr.io/r/base/print.html),
[summary()](https://choxos.github.io/krt/reference/summary.krt_validation_report.md),
and
[as.data.frame()](https://choxos.github.io/krt/reference/as.data.frame.krt_validation_report.md)
methods. `valid` is `TRUE` when there are no `error` findings.
