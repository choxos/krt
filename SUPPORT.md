# Getting help with krt

- Read the documentation and vignettes at
  <https://choxos.github.io/krt/>.
- Search the [issue tracker](https://github.com/choxos/krt/issues) for
  similar questions.
- For usage questions, open a “Question” issue with a minimal
  reproducible example.
- For bug reports and feature requests, use the corresponding issue
  templates.

Please include the output of
[`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html) and
`packageVersion("krt")` when asking about unexpected behavior.
